A tiny Node program that writes one original fortune-cookie line for a software developer — a wry prophecy about hunting a bug all week and finding it in the one line you trusted too much to reread — to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
